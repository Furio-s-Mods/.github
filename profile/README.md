# Furio's Mods

This organization hosts Vintage Story modding projects developed by [@Furio-l](https://github.com).

---

## Development Setup

The projects within this organization are built using the following specifications:
* **Vintage Story Version:** v1.22
* **Framework:** .NET 10
* **IDE:** VS Code

---

## Contributions and Feedback

Contributions, feedback, and feature requests are always welcome. Please use the Issues tab within the specific repository to report bugs or suggest features.

---

## Support

This is a non-commercial passion project supported entirely through community interaction, feedback, and code collaboration. Plans to establish a framework for financial donations are currently under consideration.
